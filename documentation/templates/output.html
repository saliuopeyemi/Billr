    Merchant Register

    This API allows registering of a merchant. N.B:A merchant admin is automatically created for the merchant.

    Endpoint:/merchant/register/

    Method: POST

    Payload

    {

'business_email':'*****',

'business_name':'*****',

'business_type':'*****',

'phone_number':'*****',

'full_name':'*****',

'password1':'*****',

'password2':'*****',

'web_url (**optional)':'*****',

}
